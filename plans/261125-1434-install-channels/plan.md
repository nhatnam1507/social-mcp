# Install channels: Homebrew, winget and Linux packages

> **Cancelled (2026-11-25).** The user chose to keep the curl/irm one-liner as the only install path for
> now. Kept for reference if package-manager channels are revisited; nothing here was implemented.

## Overview

The curl/irm one-liner stays the primary install. This plan adds package-manager channels, all generated by
GoReleaser from the same tag (it builds on `261125-1413-pr-gate-make-targets`, which introduces
`.goreleaser.yaml`):

| Channel | User command | Upgrade |
|---|---|---|
| Homebrew tap | `brew install nhatnam1507/tap/social-mcp` | `brew upgrade social-mcp` |
| winget | `winget install nhatnam1507.SocialMCP` | `winget upgrade nhatnam1507.SocialMCP` |
| `.deb` / `.rpm` | download from the release, `sudo apt install ./social-mcp_<v>_amd64.deb` or `sudo dnf install ./social-mcp-<v>.x86_64.rpm` | install the newer file |

Scoop is not included (user choice). Prereleases never reach Homebrew or winget.

## Locked decisions

- License: MIT, added as `LICENSE` and declared in every package's metadata (user choice).
- Homebrew: a public `nhatnam1507/homebrew-tap` repo, updated by GoReleaser on each stable release. Unsigned
  macOS binary; the cask clears the quarantine flag after install instead of paying for Apple signing (user
  choice).
- winget: GoReleaser pushes the manifest to the user's fork of `microsoft/winget-pkgs` and opens a PR to
  upstream on each stable release. Package identifier `nhatnam1507.SocialMCP` (permanent once published).
- Linux: `.deb` and `.rpm` attached to the GitHub Release (no hosted apt/dnf repository). The package installs
  only the binary to `/usr/bin/social-mcp`; no system service, because the daemon runs per user.
- Setup split (user choice): Claude creates `nhatnam1507/homebrew-tap` and the `winget-pkgs` fork with `gh`
  after the user confirms; the user creates the token and stores it as a repo secret. Tokens never pass
  through Claude.
- Raw binaries and `SHA256SUMS` stay exactly as they are, so the one-liner installers are unaffected. Any
  archives a channel needs are added alongside them, never instead of them.
- Every package tells users to restart the daemon after an upgrade (`social-mcp daemon stop` then `start`),
  matching the installers.

## Acceptance criteria

- `LICENSE` (MIT) exists; GitHub shows the repo as MIT.
- `make release-check` passes and `make dist` additionally produces the `.deb` and `.rpm` files (plus any
  archives Homebrew or winget need), while the six raw binaries and `SHA256SUMS` are unchanged in name and
  format.
- A stable release (for example `v0.1.0`, pushed only after user confirmation):
  - updates `nhatnam1507/homebrew-tap`; `brew install nhatnam1507/tap/social-mcp` on macOS installs a binary
    that runs without a Gatekeeper prompt and prints the tag from `social-mcp version`;
  - opens a PR to `microsoft/winget-pkgs` for `nhatnam1507.SocialMCP` with that version; once Microsoft
    merges it, `winget install nhatnam1507.SocialMCP` works;
  - attaches `.deb` and `.rpm` files that install with `apt` and `dnf` in clean Ubuntu and Fedora containers.
- A prerelease tag publishes the GitHub prerelease (with `.deb`/`.rpm`) but changes neither the tap nor
  winget.
- README `## Install` keeps the one-liners first and lists the Homebrew, winget and Linux package commands.

## Risks

- **Homebrew on Linux.** GoReleaser now generates Homebrew casks; check whether casks install on Linux with
  current Homebrew. If not, the tap is macOS-only and Linux users use the one-liner or the packages; README
  says so.
- **Channel archive formats.** Casks and GoReleaser's winget support may require archives (`tar.gz`, `zip`)
  rather than raw binaries. If so, add archive entries with their own `id` for those channels only.
- **winget review delay.** Microsoft reviews every PR; the first submission can take days and may need
  responses to bot validation. A new version is not installable until merged.
- **Token expiry or scope.** If the token expires or lacks rights, GoReleaser publishes the GitHub Release
  but fails the tap or winget step. Rerun the release job after fixing the secret. Record the expiry date.
- **Partial releases.** Publishing order is GitHub Release first, then channels; a failed channel never
  removes the release.
- **Permanent names.** The winget identifier and the tap name are hard to change once users install them.
